e-Speak is an intelligent civic issue reporting platform that empowers citizens to report public service problems with real-time AI assistant guidance. The system integrates a dual-layer AI architecture combining natural language processing with RAG (Retrieval-Augmented Generation) technology, utilizing Sentence Transformers for semantic embeddings and FAISS vector database for intelligent similarity search across thousands of municipal complaint datasets. Users receive smart suggestions for issue categorization, priority levels, and photo documentation through real-time form analysis, while a global chatbot provides instant civic knowledge insights powered by PyTorch deep learning and Hugging Face Transformers models. Built with React 18 frontend, Django REST backend, PostgreSQL database, and JWT authentication, e-Speak demonstrates 95% adoption of AI recommendations, 70% improvement in resolution times with photo evidence, and 92% accuracy in duplicate detection. The platform leverages Socrata OpenData API integration for 311 complaint data ingestion, Leaflet map integration for location-based issue mapping, and Clerk-managed user authentication, creating a comprehensive solution for democratic participation, urban infrastructure improvement, and data-driven civic governance that reduces citizen friction while enhancing municipal service quality.
